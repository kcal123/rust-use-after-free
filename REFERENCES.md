# References and tools

These are useful sources for understanding and checking the examples in this project.

- [The Rust Programming Language — Understanding Ownership](https://doc.rust-lang.org/book/ch04-01-what-is-ownership.html): how Rust ownership and cleanup work.
- [The Rust Programming Language — References and Borrowing](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html): borrowing and rules that prevent invalid references.
- [Rust error E0505](https://doc.rust-lang.org/error_codes/E0505.html): explanation of moving a value while it is borrowed.
- [Rust Playground](https://play.rust-lang.org/): used for the Rust compilation experiment.
- [Compiler Explorer](https://godbolt.org/): used to compile and execute the C example.
- [GCC instrumentation options](https://gcc.gnu.org/onlinedocs/gcc/Instrumentation-Options.html): documentation for `-fsanitize=address`.
